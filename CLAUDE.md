# 代理人路標

- 用語：命名、寫註解或文件前，先查 [GLOSSARY.md](GLOSSARY.md) 的名詞與「避免」清單。
- 雙語：改文件、docstring 或註解時，依[雙語文件維護規則](docs/documentation-policy.zh-TW.md)。
- 審查：審查 diff 時，套用 [CODING_STANDARDS.md](CODING_STANDARDS.md) 的判斷規則。
- 測試：測試、ruff 與文件檢查的指令在 [README](README.md)「開始執行」一節；先跑改到的測試檔，再跑完整測試。

# Agent pointers

- Terms: before naming things or writing comments or docs, check [GLOSSARY.md](GLOSSARY.md#en) for the term and its avoid list.
- Languages: when changing docs, docstrings or comments, follow the [bilingual documentation rules](docs/documentation-policy.zh-TW.md#en).
- Review: when reviewing a diff, apply the judgement rules in [CODING_STANDARDS.md](CODING_STANDARDS.md#en).
- Tests: the test, ruff and documentation-check commands are in the [README](README.md#en) section "Run the pilot"; run the changed test files first, then the full suite.
