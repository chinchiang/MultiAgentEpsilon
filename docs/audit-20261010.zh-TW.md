# 2026-10-10 儲存庫審視與修正

審視起點為正式 main `28be2e0`（PR #20 合併後，930 項測試、32／0 正例、32／9 指定缺陷與簽章通過，[run 37911499955](https://github.com/chinchiang/MultiAgentEpsilon/actions/runs/37911499955)）。本文件描述新增修正；舊基準的成功不等於本輪已驗收，合併前仍須獨立審查與正式 CI。

## 安全判定與 oracle

閘門判定本身沒有找到「錯誤卻放行」的路徑。真正的缺口在授權 oracle 與隔離核對，下列每項都先以舊程式重現，再證明新版攔截。

| 問題 | 修正與驗證 |
|---|---|
| 延遲副作用逃過 oracle | 舊版每個案例只比對該次請求前後快照。回應後 0.3 秒才寫入的跨租戶變更，舊 oracle 為 0 失敗。新版自行維護預期狀態，案例之間或最後靜置期間的任何變動都使新案例 `no delayed or out-of-band state changes` 失敗。 |
| 端點與身分狀態組合缺漏 | PATCH 與匯出從未測匿名、偽造、過期或已登出身分。寫入端點改用較弱工作階段檢查的候選，舊 oracle 為 0 失敗。新增 9 個案例後恰好攔下 4 個。 |
| 回應比對忽略型別 | Python 的 `1 == True == 1.0` 會讓型別錯誤的 JSON 通過。改為遞迴型別嚴格比對。 |
| 輸入邊界造成伺服器錯誤 | 越界 ID 與 NUL 字元原本變成 500。fixture 改回 422，oracle 新增兩個邊界案例。 |
| 隔離設定在評估後才核對且不完整 | 改為兩個容器都在送出任何請求前核對網路、唯讀根目錄、特權、能力、記憶體與 swap、程序數、CPU、檔案描述元、使用者與映像。並加上 `--pull=never` 與 DB `/tmp` 大小限制。 |
| oracle 資料庫連線沒有鎖逾時 | 候選可鎖住資料表讓 oracle 等到整體逾時。現在 2 秒鎖逾時、5 秒查詢逾時。`search_path` 改為 `pg_catalog` 優先。 |

AUTH 由 32 個案例擴為 44 個，指定缺陷仍為相同的 9 個。真實隔離回歸由七種缺陷變體增為九種。

## 掃描、依賴與政策

- **OSV 套件名稱：** OSV 保留 PyPI 原始拼寫（例如 `Jinja2`）。舊版精確比對會把真實公告誤判為查詢失敗，現改用 PEP 503 名稱比對。已撤回的公告不再讓每次執行失敗。
- **套件政策型別：** `allowed_packages` 若為字串會變成子字串比對，冷卻期為 0 會停用延遲。現在先嚴格檢查型別與範圍，才會聯絡套件庫。
- **候選 git 歷史：** 候選的 `.git/info/grafts` 能截斷要掃描的歷史，`i18n.logOutputEncoding` 能把提交訊息轉成掃描器讀不懂的編碼。兩者都已覆寫，並以真實 Gitleaks 回歸證明舊版漏掃。CI 的全新 checkout 不帶這些本機設定，因此只影響本機掃描攻擊者提供的儲存庫。
- **Gitleaks 執行檔：** 先讀入位元組驗證雜湊，只執行私有副本，消除驗證與執行之間的替換空窗。
- **歷史內容：** 與工作樹相同的歷史內容不再重複占用掃描預算，報告也列出未掃描的保留路徑。
- **證據一致性：** G2 摘要發現數必須等於證據清單長度。缺少必要 gate 時，不會保留先前的 ALLOW。

## CI 與部署範本

- **突變測試：** 整批期限 20 分鐘，原本與 20 分鐘的評估 job 共用時間。現改為獨立的 30 分鐘 job，最終必要檢查與發布器都要求它成功。
- **文件與靜態檢查：** 文件檢查改為也對候選執行（只讀取、不執行）。新增 ruff 靜態檢查，以 `--isolated` 固定規則，候選設定無法放寬。
- **`edited` 事件：** 刻意不在 job 層級略過。略過的同名檢查會被規則集當成通過，契約測試防止日後誤加。
- **發布器鎖與上限：** 各 PR 實例改為最多排隊 60 秒並錯開啟動，不再一起撞鎖失敗。來源上限 500 檔、API 上限 600 次，並有測試確保儲存庫保有餘裕。
- **runtime 映像：** 候選執行映像不再安裝 pytest 等測試工具。

## 腳本、模型層與測試

- **腳本參數：** 所有入口腳本的 `--help` 都不會啟動管線、清理、安裝或網路動作。
- **退出碼：** 統一為 0 成功、1 判定失敗、2 參數錯誤、3 基礎設施錯誤。
- **治理與工具：** `audit_merge_protection.py` 必須指定 `--pr`。guard 拒絕無法執行的信任政策。AWS CLI 只在執行檔雜湊與驗證安裝時的紀錄一致時重用。
- **模型目的地：** GLM 與 LM Studio 的 API 金鑰只會送到模型 RoE `allowed_remote_hosts` 列出的主機；LM Studio 的字面 loopback 不需列入。供應商設定移入 `security_harness/llm/config.py`，函式庫不再匯入命令列模組。
- **模型證據：** 單次 HTTP 逾時另記為 `IO_TIMEOUT`。每次呼叫記錄供應商是否回報輸出用量。
- **測試精確度：** 84 個原本只檢查例外型別的測試，改為比對實際訊息。發布器的 39 種偽造攻擊各自要求預期的拒絕碼。
- **警告與 TestClient：** pytest 把任何警告視為失敗。開發用 oracle 改為本機真實 HTTP，移除棄用的 TestClient。
- **突變範圍：** 新增套件政策、型別嚴格比對、容器核對與模型 RoE。8 個存活的邊界突變促成新的邊界測試，最終 206 個突變全數攔截。

# Repository audit and fixes: 2026-10-10

The starting point is reviewed main `28be2e0`: PR #20 merged, 930 tests, fixed 32/0, seeded 32/9 and verified signatures in [run 37911499955](https://github.com/chinchiang/MultiAgentEpsilon/actions/runs/37911499955). This record describes new fixes. Earlier baseline success does not establish this change; independent review and the formal CI run are still required before merge.

## Decisions and the oracle

No path was found where an error turns into ALLOW. The real gaps were in the authorization oracle and isolation verification. Each item below was reproduced against the old code before the fix was shown to block it.

| Finding | Fix and verification |
|---|---|
| Delayed side effects escaped the oracle | Each case compared only its own before/after snapshots. A cross-tenant write scheduled 0.3 s after the response produced zero failures in the old oracle. The oracle now keeps its own expected state; any change between cases or during a final settle period fails the new case `no delayed or out-of-band state changes`. |
| Endpoint and identity-state gaps | PATCH and export were never tested with anonymous, forged, expired or logged-out identities. A candidate whose write endpoint used a weaker session check produced zero failures in the old oracle. Nine new cases catch exactly four failures. |
| Comparison ignored types | Python treats `1 == True == 1.0`, so mistyped JSON passed. Comparison is now recursive and type-strict. |
| Input boundaries caused server errors | Out-of-range IDs and NUL bytes produced 500 responses. The fixture now returns 422, and two boundary cases were added. |
| Isolation checked late and partially | Both containers are now verified before any request: network, read-only root, privileges, capabilities, memory and swap, process count, CPU, file descriptors, user and image. Images are never pulled, and the DB `/tmp` is size-bounded. |
| No lock timeout on oracle DB connections | A candidate could lock a table and stall the oracle until the overall timeout. Connections now have a 2 s lock timeout and a 5 s statement timeout, and `pg_catalog` leads the search path. |

AUTH grows from 32 to 44 cases with the same nine seeded defects. Real-isolation regressions grow from seven to nine defect variants.

## Scanning, dependencies and policy

- **OSV package names:** OSV keeps published PyPI spelling (for example `Jinja2`). The old exact match turned a real advisory into a misleading query failure; PEP 503 names are now compared. Withdrawn advisories no longer fail every run.
- **Package policy types:** A string `allowed_packages` would become a substring match, and a zero cooling period would disable the delay. Types and ranges are now checked before any registry call.
- **Candidate Git history:** A candidate's `.git/info/grafts` could truncate scanned history, and `i18n.logOutputEncoding` could hide commit metadata from the scanner. Both are overridden, and real Gitleaks regressions show the old scan missed them. CI's fresh checkout does not carry such local settings, so this affected local scans of attacker-supplied repositories.
- **Gitleaks binary:** The scanner bytes are verified, then only a private copy is executed, closing the gap between verification and execution.
- **History content:** History content identical to the worktree no longer counts twice against the scan budget, and the report lists the reserved paths that were not scanned.
- **Evidence consistency:** The G2 summary count must equal the evidence finding list, and a missing required gate can never keep an earlier ALLOW.

## CI and deployment templates

- **Mutation tests:** The campaign's 20-minute deadline shared the 20-minute evaluator job. It now runs in its own 30-minute job, and the final required check and the publisher require that job.
- **Documentation and static checks:** Documentation checks now also run on the candidate (read-only). New ruff static checks use `--isolated`, so candidate configuration cannot relax them.
- **`edited` events:** They are deliberately not skipped at job level, because a skipped same-name check would satisfy the ruleset. A contract test prevents adding that skip later.
- **Publisher lock and limits:** PR instances queue up to 60 seconds with jittered start instead of failing together. Limits are 500 source files and 600 API calls, with a headroom test.
- **Runtime image:** The candidate runtime image no longer installs pytest or other test tools.

## Scripts, model layer and tests

- **Script arguments:** `--help` on every entry point starts no pipeline, cleanup, installation or network action.
- **Exit codes:** 0 success, 1 decision failure, 2 usage error, 3 infrastructure error.
- **Governance and tools:** `audit_merge_protection.py` requires `--pr`. The guard refuses a trust policy it cannot enforce. The AWS CLI is reused only when its executable matches the digest recorded at verified installation.
- **Model destinations:** GLM and LM Studio keys reach only hosts listed in the model RoE's `allowed_remote_hosts`; LM Studio's literal loopback needs no entry. Provider configuration moved to `security_harness/llm/config.py`, so the library no longer imports a CLI module.
- **Model evidence:** Single HTTP timeouts are recorded as `IO_TIMEOUT`, and each call records whether the provider reported output usage.
- **Test precision:** 84 tests that checked only the exception type now match the actual message. The publisher's 39 spoofing attacks each expect their intended denial code.
- **Warnings and TestClient:** pytest treats any warning as an error. The development oracle now uses real loopback HTTP, removing the deprecated TestClient.
- **Mutation scope:** Package policy, typed comparison, container verification and model RoE were added. Eight surviving boundary mutants led to new boundary tests, and all 206 mutants are now killed.
