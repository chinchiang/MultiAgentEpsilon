# 2026-10-09 儲存庫審視與修正

審視起點為已核准 main `438d7a4`（787 項回歸、32／0 正例、32／9 指定缺陷與簽章通過）。此文件描述新增修正，不能把舊基準的成功當成本輪已驗收。

| 問題 | 修正與驗證方式 |
|---|---|
| 模型 RoE 忽略未知供應商 | 原版可接受未知名稱；現在驗證非空、唯一、明確允許的供應商集合，在呼叫前拒絕未知／格式錯誤名稱。 |

| GLM 畸形 choices 被歸為不明失敗 | 共用嚴格文字 chat parser，非物件 choice 明確歸為非法回應，不會成功或執行工具。 |

前兩項以舊基準函式與合成反例重現後，再驗證新版拒絕；其餘按解析契約與邊界新增回歸。測試數量不是安全品質百分比，拒絕畸形證據也不等於已部署專用檢查來源。

## 新增功能

- LM Studio 文字 adapter、精確模型清單／回應識別、loopback 限定 HTTP、遠端 HTTPS、JSON schema 與既有限額／清理；詳見 [設定文件](lmstudio.zh-TW.md)。離線測試包含真實本機 HTTP 測試伺服器與完整收集／評分／清理流程，不冒充 Nemotron 真實推論。
- 分批比較驗證精確版本／RoE／取樣／輸出預算、唯一執行／呼叫／審查 ID、平衡輪次與分析重算；拒絕重播、混版、模型名稱變更與竄改。先加總 TP／TN／FP／FN，再算比率；不把多模型一致視為偏誤降低。
- 同檔雙語文件、CLI help、程式文件字串／人工註解、設定與部署說明；四張雙語圖與完整目錄樹同步。機器產物與功能性提示詞維持原契約，界線見 [文件維護規則](documentation-policy.zh-TW.md)。

## 命名空間審查

已重現 `scripts/` 隱含命名空間被搜尋路徑後方同名正式套件取代；`tests/` 也有相同結構。新增明確 `__init__.py`，讓本專案套件不與外部同名目錄合併；pytest 與 helper 使用同一 `tests.*` 模組身分。操作模組原先在匯入時反覆把根目錄插入全域 `sys.path`，現在僅直接命令列執行才設定，匯入與 reload 不改搜尋路徑。

模型實作摘要亦補上套件初始化、模型操作入口、整個共用核心及依賴鎖定；八種初始化／共用模組／CLI／lock 變更均須使摘要改變，避免跨批次混用。

回歸在獨立 Python 程序放入外部同名套件、惡意 cwd／PYTHONPATH 與假 `json.py`，確認本專案套件與 `python -I` 入口未被取代。未發現 `import *` 或候選內容直接匯入可信 host；候選 `/candidate` 路徑只存在隔離容器。這不代表能抵抗可信 host 內任意已執行 Python 程式竄改 `sys.modules`，也不保證未使用 `-I` 的任意啟動方式。

另修正 `run_security.py --help` 原先被記為執行失敗的問題；純說明請求現在正常退出，不啟動安全管線或建立 BLOCK 報告。真正參數與設定錯誤仍保留早期錯誤證據。

## Added capabilities

LM Studio text integration enforces exact catalog/response model IDs, loopback-only HTTP/remote HTTPS, schema and existing budget/cleanup controls. Offline coverage includes a real localhost fixture server and collection/scoring/cleanup, not actual Nemotron inference. See [setup](lmstudio.zh-TW.md#en).

Cross-batch comparison revalidates versions/RoE/sampling/output budgets, unique runs/calls/reviews, balanced repetitions and recomputed analysis. Replay, mixed versions, changed labels, and tampering reject. Counts are pooled before ratios; agreement does not establish bias reduction.

Same-file bilingual docs, CLI help, docstrings/authored comments, configuration/deployment explanations, four diagrams and full tree are maintained. Machine artifacts and functional prompts retain their contracts; see [policy](documentation-policy.zh-TW.md#en).

## Namespace audit

A foreign regular scripts package later on sys.path could replace the repository's implicit namespace; tests had the same structure. Explicit __init__.py files prevent merging with unrelated directories and give pytest/helpers one tests.* identity. CLI modules previously repeatedly prepended ROOT on import; now only direct CLI entry configures the path, while imports/reloads leave it unchanged.

Implementation digests now include package initializers, model entry points, the shared core and dependency lock. Eight initializer/shared-module/CLI/lock mutations must change the digest, preventing cross-batch implementation mixing.

Fresh-process regressions inject same-name external packages, hostile cwd/PYTHONPATH and a fake json.py, verifying repository package identity and python -I entry points. No wildcard imports or direct candidate imports on the trusted host were found; /candidate insertion occurs only inside isolation. This does not defend against arbitrary already-running trusted-host Python altering sys.modules, or promise safety for every non-isolated launch.

Pure run_security.py --help now exits normally without starting evaluation/creating BLOCK evidence; actual argument/configuration errors retain early failure records.
